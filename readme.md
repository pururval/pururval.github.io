# Personal Portfolio

Personal portfolio website: [pururval.github.io](https://pururval.github.io/)

## Structure

- `index.html` - Active landing page
- `archive/legacy-pages/` - Previous site versions
- `icons/` - Site favicon

## Run Locally

Start a local web server:

```sh
python3 -m http.server 8000
```

Open <http://localhost:8000> in your browser.
